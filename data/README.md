# data/

`vtest.avi` (8.1 MB, 795 frames, 768x576, 10 fps) is the pedestrian sample video from the
[OpenCV project](https://github.com/opencv/opencv/blob/4.x/samples/data/vtest.avi)
(`samples/data/vtest.avi`), redistributed here under OpenCV's open-source license (BSD-3-Clause
at the time the sample was added; see the OpenCV repository for license terms). It is used only as
a demo input.

The scene calibration for this video is in [`config/vtest_calibration.json`](../config/vtest_calibration.json).
